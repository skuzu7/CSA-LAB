# Code of Conduct

This project exists to teach and evidence defensive security practice.

- Be precise, be kind, cite sources. Disagree with the claim, not the person.
- No harassment, doxxing or sharing of real victim data, in any channel connected
  to this project.
- No contributions that target systems without authorization, add offensive
  tooling, or weaken the [authorization policy](AUTHORIZATION.md).
- Report conduct concerns privately to the maintainer through the contact in
  [SECURITY.md](SECURITY.md). The maintainer may edit, reject or remove any
  contribution and may block participants who break these rules.
