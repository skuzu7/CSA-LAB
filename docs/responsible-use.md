# Responsible use

- This repo teaches defense: every attack step exists to justify and verify a patch.
- Do not point any PoC here at systems you don't own. The tests hardcode 127.0.0.1 for a reason.
- Do not use the vulnerable app as a template for production. It is a punching bag, not a starter kit.
- Report real issues per SECURITY.md. Keep it coordinated, keep it legal.
